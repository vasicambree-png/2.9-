## 构建

固件在 MounRiver 中打开 `CH584_V1_0_1/CH584M_TFT_HB.wvproj` 并构建。仓库保留 `.project`、`.cproject`、`.template`、调试配置和必需的 SDK `.a` 文件；`obj/`、`Debug/`、`Release/` 及编译中间文件按 `.gitignore` 排除。

上位机在 Windows PowerShell 中进入 `上位机验证工具`，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

编译器使用 Windows 内置 .NET Framework C# 编译器，无需安装第三方依赖。重新构建前请先关闭已运行的助手 EXE。
