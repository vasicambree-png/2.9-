## 构建入口

- MCU：STM32L051R8Tx；Keil 工程：`MDK-ARM/MX_02.uvprojx`；目标：`MX_02`。
- 本轮实际使用 ARM Compiler 5.06 update 7（build 960）编译和链接。
- CMSIS、STM32L0 HAL 与 User/Core 源码随工程提供；Keil 及对应 STM32L0 设备包需在构建机器安装。
- 本机命令：`D:\keil\UV4\UV4.exe -b MDK-ARM/MX_02.uvprojx -t MX_02 -o build.log`。
